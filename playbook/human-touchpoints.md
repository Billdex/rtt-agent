# 人机边界清单（H 编号）

> 这里列出的每一处，**AI 都必须停下来说一句具体的话，然后等人类动作**。
> 不允许"自己试三次看看"——历史上每一次多试，代价是一轮数据、一件买不回来的装备，或一次经验减半。

## 通用规则

1. 到达边界 → 立刻停手，用**一句话**说明"我需要你做什么"，附上**已经确认过的事实**（不附推测）。
2. 人类动作完成后，AI 必须做一个**独立校验**（重载重读 / 换页读数 / 文件差异），不能假设"他说做了就是做了"。
3. 人类拒绝时 → 记录在任务单的「前置」里，换别的任务单，不要反复请求。
4. 不确定是不是边界时，**按边界处理**（多问一句的成本远低于错一步）。

## H-01 登录与会话

- **触发**：`rtt.mjs status` / `tabs` 报错、页面出现"登录"字样、`connectOverCDP` 连不上且重启浏览器无效。
- **人类动作**：在弹出的独立 profile 窗口里自己登录。
- **AI 该说**："浏览器会话已失效，请在那个独立窗口里登录一次，完成后告诉我。我不会读取密码或 Cookie。"
- **校验**：`rtt.mjs status` 能读出页面标题与正文。
- **红线**：永不索取 / 读取 / 保存密码、Cookie、Token；`chrome-profile/` 不提交、不外发。

## H-02 开局（自动加入开关）

- **触发**：任何要"开始跑局"的动作。`button.auto-enter-toggle` 一开就开始倒计时（实测"9 秒后按条件加入"）。
- **人类动作**（二选一）：确认配置已经改好并允许开启；或自己点开关。
- **AI 该说**："我打算开自动加入：N 局 / 间隔 N 分钟 / 资金下限 N（预估消耗 N GB）。确认后我再点开关。"
- **前置顺序**：**先改完配置 → 重载复核 → 最后开开关**（T-06）。
- **校验**：重载后读 `aria-pressed` 与按钮文案；确认没有局在跑时才能开。
- **注意**：这是"点一下就花钱开始跑"的按钮，属于 H-04 的特例，必须先报备。

## H-03 策略写入（滑杆 / 数字框 / 优先点位 / 高级模式）

- **触发**：要改 `/strategy` 上任何值，或写 `priorityNodes`，或碰「高级模式」。
- **人类动作**：AI 改完后，人类**亲自重载一次确认**；`priorityNodes` 直接由人类点（自动化约 1/3 失败）。
- **AI 该说**："策略已改为 X（原值 Y），依据是第 N 局的原文 `…`。请刷新策略页确认这一项还在，并确认其余项没变。"
- **校验**：`strategy-snapshot.mjs` 前后各跑一次，diff 只允许出现预期的那一项；`changeCount = 0` 就是没改成。
- **红线**：绝不勾「高级模式」（G-24）；绝不点「保存策略」以外的破坏性按钮。

## H-04 花钱

- **触发**：加载配装（按缺口扣钱）、自动补货、治疗、买装备、升级仓库/设施。
- **人类动作**：批准金额。
- **AI 该说**："缺口 N 项，预计扣 N GB（逐项列出：A N GB、B N GB）。当前现金 N。确认吗？"
- **门槛**：单次 > 20,000 GB 或单轮累计 > 50,000 GB 必须报备；缺口为 0 / 费用为 0 时不用问。
- **校验**：现金增量与报价一致；不一致就停下查（G-17）。

## H-05 不可逆资产操作

- **触发**：换胸挂/背包、清仓/出售、交任务（消耗 FIR 库存）、拆解、丢弃、使用一次性资产。
- **人类动作**：确认对象清单。
- **AI 该说**："要清掉这 N 件（总价值 N GB，预计到账 N–N GB）。其中 X 是任务物 / 钥匙 / 买不回来的装备，我会保留。确认？"
- **固定保留**：钥匙、任务物、一次性资产清单（见 `STATE.md` §2）、配装里"无法补购"的件。
- **校验**：换容器后看 `携带总价值` + `胸挂 +N`（G-19）；清仓后看体积/件数差（M-05）。

## H-06 轮次目标与验收口径

- **触发**：每轮开工前；以及任何"要不要宣布改善"的时刻。
- **人类动作**：确认这一轮属于**哪条线**、唯一变量是什么、"改善"的判据数字。
- **AI 该说**："本轮任务单：线 A，变量 X（原 Y → 新 Z），判据 = 旧城区全样本 GB/回合 > 1,083（当前 n=8）。驳回或确认？"
- **校验**：任务单写进 `progress/tasks/<id>.md` 后才开始执行。
- **为什么必须有**：没有这一步，AI 会用"这一轮做了什么"当成果，人类得自己判断有没有用。

## H-07 自动化与游戏规则风险

- **触发**：首次在本仓库运行、或游戏更新了用户协议/反作弊提示。
- **人类动作**：自行确认是否接受账号风险。
- **AI 该说**："自动化托管可能违反游戏用户协议，风险需要你自己判断；我按你的决定执行或停止。"
- **红线**：不替人类做这个决定，不提供规避检测的方法。

## 反模式（出现过，别再犯）

| 反模式 | 后果 | 替代做法 |
| --- | --- | --- |
| 自动写入失败后连试 3 次 | 白耗时间，还可能写脏草稿 | 第 2 次失败就停，报 H-03 |
| 自己开自动加入"看看能不能跑" | 未经批准花钱、污染批次数据 | 先报 H-02 |
| 用 `.click()` 点同名按钮 | 点了没反应，循环重启 | T-09 |
| 归一因时用结算数字推理 | 改错参数 | M-01 |
| "顺便"换一下配装 | 本轮实验作废 | 两条线互斥，见 `strategy-line.md` |
