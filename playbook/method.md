# 实验纪律（M 编号）

> 跨游戏通用，与具体地图/装备无关。**两条目标线都受这份文件约束。**
> 违反任意一条，本轮结论作废——不是"打个折扣"，是作废。

## M-01 结算只说结果，日志才说过程（旧 6）

同样是"撤离成功"，原因可以是弹尽、缺药、容器满、到回合上限、策略主动触发。四种原因对应四种完全不同的修法。
**只看结算就会改错参数。**

- 归因必须引用日志原文（`[回合号] 原文`），不能写"应该是弹药不够"。
- 结局定位**取日志最后一条命中**：中段击杀日志里也常出现 `死亡` / `致命攻击`，取第一处会把"击毙敌人"当成"本局阵亡"
  （实测把 09:09 那局的撤离定位到第 173 回合的一次击杀）。
- 同一件事有多种写法，别只匹配一种：

| 概念 | 见过的原文写法 |
| --- | --- |
| 弹尽 | `已无弹可用` / `没有可用子弹` / `弹药耗尽` |
| 撤离成功 | `已完成撤离` / `已撤出战局，带出物资价值 N` / `成功撤出；带出价值：N` / `撤离成功，带出物资价值 N`（同批 10 局出现 4 种） |
| 提前离场 | `【匆匆撤离】…本局经验减半` |
| 阵亡 | `阵亡` / `倒地身亡` / `因…的攻击死亡` / `遭到 'X' 的致命攻击` |

## M-02 一次只改一个变量（旧 13）

- 同一轮里既换地图又改撤退线又换配装，收益变化无法归因。
- 每一项改动必须能写成"**因为第 X 局的哪条日志**"，写不出来的不许改。
- 明知会失去可归因性仍然要同改两项时（例如时间成本不允许），必须在任务单里**显式标注"本轮结论不可拆分"**，
  并在结论里只采信能单独归因的那一半（例：G-10 只采信"进攻端"）。

## M-03 主指标必须用全样本（旧 49）

同一张图，不同样本算出相反方向：

| 样本 | GB / 回合 |
| --- | --- |
| n=4 子集 | **1,619** |
| n=8 全样本 | **1,083** |
| 新配装 n=2 | **886** |

曾经差点用 n=4 宣布"新配装提升 110%"。**同一个配装，换个样本就变成低 18%。**

- 报数字必须带 **n + 时间范围**，并且用 `raid-analysis.json` 全量重算，不许手抄。
- 单局极值先当离群值，n≥3 再谈趋势。
- `收益/回合` 的分母是回合数，长短局混算要标注。

## M-04 外部建议必须回游戏核对（旧 22）

别人（含其他 AI、含玩家口传）给的数值，以**百科 → 物品详情**为准。实测抓出 4 处错（配件人机值、商人等级、有没有货、最优射程），
以及玩家经验 2 处错（肉铺不存在、信号塔要指通信塔，见 G-13）。

**核对成本 1 分钟，验证成本 1 局。**

## M-05 "点了"不等于"生效了"

- `element.click()` 不做命中测试；Playwright 默认 dismiss 原生对话框。所以"日志显示已点"可能什么都没发生。
- 每个写操作都要一个**独立的成功判据**：卡片消失 / 重载后值还在 / `携带总价值` 增量对得上 / 仓库件数差。
- 账目核对同理：同一页连读两次不算证据，换页重读（T-12）。

## M-06 证据分级：实测 / 推断 / 猜测

汇报与结案时必须标注，不许混写：

| 级别 | 定义 | 能否写进 `LESSONS.md` |
| --- | --- | --- |
| **实测** | 有日志原文或脚本输出，可复现 | 能 |
| **推断** | 有间接证据，缺一条直接验证 | 能，但必须标 `（推断）` 并写清"缺哪一条验证" |
| **猜测** | 只是解释得通 | **不能**；进 `STATE.md` 的假设表 |

反例：`配装绝对存不了面部`（推断未标）、`软撤离被判匆匆是出血导致`（猜测被当成结论用了半轮）。

## M-07 假设台账 + WIP = 1

- 同时只允许 **1 个活跃假设**，其余排队（列表在 `progress/STATE.md` §1）。
- 每个假设必须有：验证动作、单一变量、可区分的判据（"至少 2 局里能区分三种猜测之一；分辨不出来就换变量"）。
- 假设结案后才能开下一个；**分辨不出来也算结案**（写"未区分，放弃该变量"），不许无限挂起。
- 这是防止"6 个变量并行、每轮只推进一点点、人类感觉原地打转"。

## M-08 结论要能写成"触发器 → 动作"

不能写"看情况调整"。必须形如：

| 信号 | 动作 |
| --- | --- |
| 本局阵亡 | 撤退血量 +10、容器撤离阈值 −10 |
| 收益 < 目标 且未死 | 先读日志；日志里没有"无弹/缺药"就**不许**动参数 |
| 连续 2 局低于目标 | 换地图或换策略，停止微调 |
| 出现无弹 | 补到 3 局用量 |
| 交火占全局 > 50% | 先改接战距离，再考虑装备 |

写不成这个形状的"经验"，说明还没想清楚，先别写进任何知识文件。
