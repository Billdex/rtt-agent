# 任务单模板

> 用法：复制到 `progress/tasks/<日期>-<序号>-<短名>.md`，填满再动手。
> **没填完「判据」和「前置」不允许开始执行**——这两栏是防止"做完才发现方向错"的唯一手段。
> 一轮 = 一张单。跨线任务拆成多张单，不要塞进同一张。

---

# 任务单 <id>

```yaml
id: 20261111-01
线: A策略 | B经营 | 工具
状态: 待批 | 进行中 | 已结案 | 已放弃
建立: 2026-11-11 09:00
数据截点: 引用的 STATE.md 时间
```

## 1. 本轮唯一目标

一句话，必须是**一个变量**或**一个状态**，不能是"改善账号"这种。

> 例：验证"软撤离被判匆匆"是否取决于"触发时已在出口节点"。
> 反例：优化旧城区收益（多变量，无法归因）。

## 2. 依据（必须可追溯）

- 哪一局的哪条日志 / 哪个数字：
  - `第 N 局（时间） [回合号] 日志原文`
  - 或 `preflight` 输出：`缺口 2 项 / 13,744 GB`
- 对应知识条目：`G-xx` / `T-xx` / `M-xx`

## 3. 前置：需要人类做的事

| 编号 | 人类要做的动作 | 是否已完成 |
| --- | --- | --- |
| H-0x |  |  |

没有需要人类做的事就写"无"。**有的话必须先停下来问**，不要自己顶替。

## 4. 执行步骤（可直接复制）

```bash
# 1)
# 2)
```

步骤里不许出现"看情况"；分支条件写成 `若 X 则 Y`。
