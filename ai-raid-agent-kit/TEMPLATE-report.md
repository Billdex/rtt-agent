# 战报模板

> 用法：每次开新一轮，把本文复制到 `progress/report.md` 并填满；旧轮次另存为 `progress/report-YYYYMMDD.md` 归档。
> 空着的地方留 `—`，不要臆造数字。

## 基本信息

| 项 | 值 |
| --- | --- |
| 轮次 | 第 N 轮 |
| 开始 / 结束 | 2026-11-10 06:00 → 06:40 |
| 地图 | 地图 A + 地图 B |
| 策略 / 配装 | 槽位名 / 配装名 |
| 局数上限 / 资金下限 | 6 局 / 100,000 GB |
| 开始资产 | 现金 ___ GB · 仓库 ___ GB · 负重 ___ kg |
